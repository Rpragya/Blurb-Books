# Website photography

Photography downloaded from Unsplash and stored locally so the website does not depend on third-party image requests at runtime.

- Library hall: https://images.unsplash.com/photo-1568667256549-094345857637
- Library shelves and lights: https://images.unsplash.com/photo-1481627834876-b7833e8f5570
- Fiction collection: https://images.unsplash.com/photo-1519682337058-a94d519337bc
- Mystery collection: https://images.unsplash.com/photo-1518709268805-4e9042af9f23
- Science fiction collection: https://images.unsplash.com/photo-1451187580459-43490279c0fa

Book covers are generated typographic artwork from the demo catalogue, rather than representations of published editions.

The site serves resized WebP versions of these photos (`hero-library-*.webp`, `library-reading-*.webp`, `genre-*-900.webp`), generated with `cwebp`. The hero is a landscape crop of the library hall photo.
